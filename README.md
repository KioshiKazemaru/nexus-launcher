# Nexus Launcher 0.11.0 — Windows 10/11 x64

Один лаунчер для Steam и Epic Games: общий магазин с ценами обоих сервисов и общая библиотека игр со всех подключённых аккаунтов. Nexus — независимое приложение, не связанное с Valve и Epic Games. Покупка проходит в официальных магазинах; игры Epic Nexus скачивает и запускает сам, игры Steam — через Steam, работающий в фоне.

## Запуск игр без сторонних лаунчеров

Настройки: «Аккаунты» → «Запуск игр». Всё включено по умолчанию и выключается по отдельности.

- **Epic Games — без Epic Games Launcher.** Nexus запускает exe игры сам и передаёт ей одноразовый код входа подключённого аккаунта (так же работают Legendary и Heroic). Нужные данные берутся из манифеста установки Epic и каталога Epic; защищённым играм передаётся токен владения. Игры, которыми управляет EA или Ubisoft, и любые сбои автоматически передаются Epic Launcher. Время в таких запусках Nexus считает сам: Epic учитывает только свой лаунчер.
- **Облачные сохранения Epic.** Перед запуском Nexus сравнивает сохранение на ПК с облаком Epic и берёт более новое; после выхода из игры загружает изменённое. Формат тот же, что у Epic Launcher (манифест + чанки, проверено с Legendary в обе стороны и на реальных сохранениях Epic Launcher). Если сохранение изменилось и в облаке, и на ПК, Nexus спрашивает, какое оставить. Перед заменой локальное сохранение копируется в `%APPDATA%Nexus Launchersave-backups` (последние 5 копий на игру). Кнопка «☁ Сохранения» на странице игры синхронизирует вручную.
- **Steam — без окна Steam.** Играм Steam нужен клиент (защита, Steam Cloud, достижения), поэтому Nexus запускает его скрыто (`-silent`, только значок в трее) вместе с игрой и, если Steam запустил Nexus, закрывает его через минуту после выхода из игры (после выгрузки Steam Cloud).
- **Ограничения.** Нет оверлея Epic с друзьями; писать друзьям Epic нельзя (сервер чата Epic отклоняет личные сообщения сторонних программ). Вход для игр использует учётные данные Epic Launcher, опубликованные Legendary, — это серая зона правил Epic, как и импорт библиотеки.

## Что нового в 0.11.0

- **Установка без окон лаунчеров.** Игры Epic Nexus скачивает сам с серверов Epic (как Legendary): окно установки с размерами, папкой, языками и другими компонентами, DLC из библиотеки аккаунта; пауза, докачка после перезапуска, проверка файлов, обновления только изменённых файлов. Игры Steam скачивает Steam, работающий в фоне без своего окна.
- **Загрузки:** очередь (одна игра за раз, «▲ Первой»), ограничение скорости, разрешённые часы (например, ночью), уведомления Windows о готовых играх, автообновление игр Epic.
- **«Указать папку игры»:** игра, которая уже есть на диске (после переустановки Windows), добавляется без новой загрузки; недостающие файлы докачиваются. **«Переместить»** — перенос игры Epic в другую папку или на другой диск.
- **«Хранилище»:** сколько места занимают игры на каждом диске, с кнопками «Открыть папку», «Переместить», «Удалить».
- **Удаление игр** Steam и Epic прямо из Nexus.
- **Друзья и чат** в отдельных окнах: статусы «В игре», чат Steam (история, уведомления); история переписки зашифрована.
- **Режим геймпада** (как Big Picture): полный экран, большие обложки, управление геймпадом или клавиатурой; кнопка 🎮 или Guide на геймпаде.
- **Обновления Nexus** приходят из GitHub Releases репозитория KioshiKazemaru/nexus-launcher.

## Что нового в 0.10.4

Проверено вживую с настоящими аккаунтами: Steam (305 игр, время, достижения) и Epic (142 игры) подключаются и загружаются.

- **Игры Steam больше не теряются за названием Epic** (например, Hogwarts Legacy / «Хогвартс. Наследие»). Epic отдавал русские названия, Steam — английские, и одна игра считалась двумя. Теперь у игры хранятся оба названия, а метаданные Epic запрашиваются на английском (один раз на игру, результат сохраняется между синхронизациями).
- **«Имеющиеся» показывают и установленные игры**, даже если их нет в списке аккаунта (например, игры из Семейной библиотеки Steam): Steam устанавливает их только при наличии лицензии.
- **Обложки новых игр Steam:** с 2024 года картинки лежат в папках с хешем, и обычный `header.jpg` для них не существует. Теперь реальные пути берутся из `IStoreBrowseService/GetItems` (один запрос на 100 игр, один раз за запуск).
- **Цены Epic для игр из библиотеки:** если поиск Epic не вернул состав издания, игра сопоставляется по пространству имён продукта, когда в нём ровно одна основная игра (DLC не считаются). Ответ GraphQL с ошибками отдельных полей больше не отбрасывается целиком.
- **Обложки Epic:** широкая обложка элементов каталога (`DieselGameBox`) теперь используется; если широкой нет — показывается вертикальная.
- **Боковой список библиотеки:** вместо сжатого текста «Обложка недоступна» — аккуратная заглушка.
- **Сортировка по названию** не поднимает наверх названия, начинающиеся с кавычек или пробелов; учитывает русский алфавит и числа.

## Что нового в 0.10.3

Первая проверка на реальном Windows (Node 24, Electron 44): установка, lint, 120 тестов и живые запросы к Steam и Epic прошли. Найдено и исправлено в работающем приложении:

- **Инструменты Steam больше не попадают в «Скачанные игры»:** Steamworks Common Redistributables, SteamVR, Proton и среды Linux отсекаются сразу, программы (OBS Studio и т. п.) — после ответа магазина о типе приложения. Запуск при этом не ждёт сети.
- **Без входа в Steam** статус — «Не выполнен вход», а не «Проверка недоступна»: без cookie входа сеть не опрашивается.
- **Проверка входа Steam** устойчива к пустому адресу ответа у `net.fetch`, а окно магазина дополнительно передаёт SteamID страницы.
- **Журнал:** причина неудачной проверки входа записывается; отсутствующая обложка — больше не предупреждение (уровень debug с HTTP-кодом).

## Что нового в 0.10.1

- **Цены больше не перерисовывают библиотеку.** Состояние окна разделено: список игр, каталог, цены (отправляются только изменившиеся игры) и прогресс загрузки. Новая цена обновляет только свою карточку; более свежие цены из главного процесса заменяют старые ответы.
- **Загрузка игры больше не перестраивает интерфейс каждые 5 секунд.** Опрос манифестов меняет только прогресс; библиотека пересобирается, лишь когда игра действительно установилась или удалилась.
- **Обложки Epic доходят до окна сразу,** а ненайденные не ищутся повторно при каждой пересборке (повтор через сутки). Поиск обложек идёт в одном потоке.
- **Импорт желаемого не меняет аккаунт для покупок** — выбор запоминается только при покупке или раздаче.
- **Сбой главного процесса** записывается в журнал, настройки сохраняются, пользователь видит сообщение; Nexus перезапускается один раз (сбой в первые 30 секунд — закрытие без цикла перезапусков).
- **Резервная копия проверяется полностью:** отслеживания цен, время в играх и сохранённые игры пересобираются из проверенных полей, лишнее отбрасывается.
- **Журнал** больше не прячет короткие значения вроде «exit code: 1» (коды авторизации по-прежнему скрыты).
- **Обновления:** один обработчик ошибок; «не поддерживается» — только для локальной сборки без источника обновлений.
- **Игры через лаунчер:** для добавленного вручную .exe можно указать процесс игры — время считается, пока он запущен. Если файл закрылся сразу, Nexus подскажет это сделать.

## Что было в 0.9

**Библиотеки аккаунтов**

- **Steam** берёт список игр через `IPlayerService/GetOwnedGames` с токеном текущей сессии сайта. Личный API-ключ не нужен, приходят только игры, сразу с названиями, временем в игре и датой последнего запуска. Если токен недоступен, список лицензий (`dynamicstore/userdata`) фильтруется через `IStoreBrowseService/GetItems`, поэтому DLC, саундтреки, инструменты и серверы больше не попадают в библиотеку. Страница игр сообщества читается и в новом формате (`data-profile-gameslist`), и в старом (`rgGames`).
- **Epic** подключается через OAuth, как в Legendary и Heroic. Вы входите на официальной странице Epic, Nexus получает код авторизации и обменивает его на токены. Сохраняется только токен обновления, он шифруется Windows DPAPI. Загружаются библиотека и время в играх. Если вход через Google или Apple во встроенном окне не работает, есть «Войти через браузер»: войдите в браузере и вставьте `authorizationCode` в поле «Код из браузера». Импорт Legendary остаётся запасным вариантом.
- **Несколько аккаунтов.** До пяти аккаунтов Steam (у каждого своя изолированная сессия) и любое число аккаунтов Epic. «Имеющиеся» объединяют игры всех подключённых аккаунтов. На странице игры видно, если она есть на нескольких аккаунтах.
- **Данные с диска:** установленные Epic-игры читаются ещё и из `LauncherInstalled.dat`. Даты последнего запуска и время в Steam берутся из `localconfig.vdf`, вертикальные обложки — из локального кэша Steam (`appcache/librarycache`) через защищённую схему `nexus-art://`.
- **Установка Epic-игры** открывает установку в Epic Games Launcher, если известны namespace и itemId. Иначе открывается библиотека клиента.

**Одна игра из двух магазинов** (`src/matching.cjs`)

- Правила склейки по убыванию силы: ручное разделение → ручное объединение → каталог Nexus → общий ID из IsThereAnyDeal или IGDB → совпадение названия без учёта ™/®, пунктуации и слов изданий («Game of the Year», «Deluxe», «Ultimate Edition»…). Сиквелы и ремастеры не склеиваются. Два разных предложения одного магазина автоматически не склеиваются никогда.
- Близкие, но не одинаковые названия не объединяются молча. В «Имеющихся» появляется блок «Возможно, одна и та же игра» с кнопкой «Объединить». На странице игры есть кнопка «Разделить».
- В магазине склейка остаётся строгой (точное название), чтобы не сравнивать цены разных изданий.

**Магазин и цены**

- **«Где дешевле».** На карточке и в окне игры указано, в каком магазине дешевле и на сколько (сравниваются только цены в одной валюте).
- **IsThereAnyDeal (по ключу):** исторический минимум цены в Steam и Epic прямо в окне игры.
- **Раздачи Epic.** Полка «Бесплатно в Epic Games» с текущими и будущими раздачами и кнопкой «Забрать в Epic» (открывает официальную страницу). Уведомление о новой раздаче можно отключить.
- **Импорт списков желаемого** Steam (`IWishlistService`) и Epic в «Желаемое» Nexus.
- **Поиск Steam:** если HTML-выдача сломается, используется JSON `api/storesearch`. Подборки при сбое берутся из `api/featuredcategories`.
- **Каталог Epic:** если Epic отвечает 403 обычному запросу, запрос повторяется из скрытой страницы магазина в настоящем браузерном окне.

**Внешние сервисы** (необязательно, «Аккаунты → Внешние сервисы»; ключи шифруются Windows)

| Сервис | Где взять ключ | Что даёт |
|---|---|---|
| IsThereAnyDeal | isthereanydeal.com → Apps | склейка Steam/Epic, исторические минимумы цен Steam и Epic |
| IGDB | dev.twitch.tv → Applications (Client ID + Secret) | описания, жанры, обложки, склейка |
| SteamGridDB | steamgriddb.com → Preferences → API | вертикальные обложки для Epic-игр и добавленных вручную .exe |

Без ключей всё остальное работает как раньше.

**Внутреннее устройство**

- `main.cjs` разбит на сервисы: `src/main/storage.cjs` (файлы, DPAPI), `accounts.cjs`, `library.cjs`, `store.cjs`, `integrations.cjs`, `windows.cjs`, `updater.cjs`. Steam и Epic описаны в `src/platforms/` (`scanInstalled`, `launchUri`, `clientUri`, `storeUrl`).
- Чтение диска и запись настроек асинхронные. Настройки пишутся атомарно с задержкой, при выходе сбрасываются на диск.
- Состояние в окно отправляется не чаще раза в ~120 мс. Интерфейс перерисовывается не чаще раза за кадр и не во время ввода в поле. Сетка библиотеки подгружается порциями по 120 игр при прокрутке, боковой список ограничен 400 строками.
- Сохранённые в настройках игры урезаются до нужных полей, индекс магазина ограничен (LRU). Мёртвый код старой веб-проверки Epic удалён.
- Код отформатирован Prettier и проходит ESLint (`npm run format`, `npm run lint`).

**Сборка и обновления**

- Сборка через `electron-builder` в установщик NSIS (`npm run dist`). Автообновление через `electron-updater` из GitHub Releases, проверка при запуске и каждые 6 часов (можно отключить в «Аккаунтах»).
- Подпись кода: переменные `CSC_LINK` (сертификат .pfx в base64) и `CSC_KEY_PASSWORD`. Без подписи Windows SmartScreen показывает предупреждение.
- GitHub Actions: `ci.yml` (lint и тесты на Windows и Linux, тестовая сборка установщика), `release.yml` (тег `v*` → подписанный релиз), `live-api.yml` (каждую ночь проверяет живые эндпоинты Steam и Epic, чтобы узнать о поломке раньше пользователей).

## Перед первым запуском из исходников

1. Установите Node.js 22.12+.
2. Выполните `npm install`. В архиве нет `package-lock.json`, потому что зависимости изменились (добавлены `electron-updater`, `electron-builder`, `eslint`, `prettier`, `playwright`, удалён `@electron/packager`); создать его без доступа к npm было нельзя. Закоммитьте созданный lock-файл, после этого CI будет использовать `npm ci`.
3. `npm test`, затем `npm start`. Можно просто запустить `START-DEVELOPMENT.cmd`.
4. Релиз: запушьте тег `v0.10.0`. `release.yml` соберёт установщик и опубликует его в GitHub Releases того репозитория, где запущен workflow; оттуда же установленные копии получают обновления.

## Что проверено и что нет

Запустите `npm test` у себя после `npm install`.
- **Сценарии главного процесса** (без сети, на заглушке): вход Steam и Epic, объединение библиотек, перенос избранного при разделении/склейке, второй аккаунт Epic в отдельной сессии, выбор аккаунта при покупке, удаление незавершённого слота Steam, второй аккаунт Steam, резервная копия без секретов, режим без сети, диагностика без токенов, достижения, скрытие и коллекции, выход из аккаунта Epic.
- **Не проверено на реальных сервисах** (сборка шла без доступа к Steam и Epic): `GetOwnedGames` с токеном сессии (`webapi_token`), фильтр через `GetItems`, OAuth и время в играх Epic, GraphQL списка желаемого Epic, URI установки/удаления/проверки Epic, достижения Steam (`GetPlayerAchievements` с токеном сессии и XML-страница статистики), формат файла коллекций Steam (`cloud-storage-namespace-1.json`), флаги прогресса в appmanifest, API IsThereAnyDeal v3, поля IGDB `external_games`, SteamGridDB, автообновление и подпись. Эти эндпоинты неофициальные или взяты из документации сервисов. Если что-то не сработает, приложение показывает ошибку и откатывается к предыдущему способу. `live-api.yml` проверяет основные из них каждую ночь.

## Важно про правила сервисов

- Для доступа к библиотеке Epic используется публичный client_id лаунчера Epic, как в Legendary и Heroic. Официального API библиотек для сторонних приложений у Epic нет, поэтому это серая зона пользовательского соглашения Epic. Steam-часть использует сессию пользователя на сайте Steam и неофициальные эндпоинты.
- Nexus не хранит пароли, не обходит 2FA и проверки безопасности, не проводит покупки сам и не активирует ключи из сторонних магазинов.

## Использование

- **Аккаунты:** «Войти в Steam» / «Войти в Epic Games», затем «＋ Добавить аккаунт» для следующих. «Запомнить вход» сохраняет зашифрованную сессию Steam и токен обновления Epic, не пароль.
- **Библиотека → «Имеющиеся»:** игры всех аккаунтов. Сортировка по названию, по последнему запуску или по времени в игре. Под статусами аккаунтов показывается блок возможных совпадений.
- **Библиотека → «Скачанные»:** игры на этом ПК (манифесты Steam и Epic, `LauncherInstalled.dat`, добавленные .exe).
- **Магазин:** витрина Steam и Epic, раздачи Epic, поиск по обоим магазинам, фильтры цен, «где дешевле», отслеживание цены.
- **Скидки:** отслеживание до 100 предложений, проверка каждый час, пока Nexus открыт.
